# LG CES 2027 design reference

Internal LG design review concept based on https://www.lg.com/global/ces2026/.

The reference page structure, original images, videos and links are retained. The hero uses new concept artwork for CES 2027; its wording is provisional and is not an approved LG campaign.

## View

This repository contains a buildless static website. Serve its root directory.

For GitHub Pages, open repository Settings → Pages, choose "Deploy from a branch", select "main" and "/ (root)", then save.
